02 / 规则

CheckSpec

用业务语言维护检查规则；保存前会执行完整配置校验。

选择一条规则查看和编辑。
规则说明 定义这条规则检查什么、适用于哪里。
适用条件与证据 限定何时执行，并声明检查所需的页面事实。
所需证据 执行前必须采集到的事实。选择不足会导致规则无法可靠判断。
执行方式 绑定已注册的能力；能力本身决定使用代码检查或模型判断。
跨页面比较方式 仅用于“用户旅程”规则，定义要比较哪些节点。
规范依据 每条规则至少关联一项内部或外部规范，用来解释“为什么检查”。
高级模式：直接编辑 YAML 适合维护未覆盖的字段；保存后会回填到表单。
