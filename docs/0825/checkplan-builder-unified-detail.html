共同点三个 Builder 共享 AuditProfile 和 CheckSpec Registry，但不会处理非本 Scope 的规则。
Page 的角色每个页面先生成自己的 Page CheckPlan 和 Page 结果，为后续 Transition / Journey 提供事实。
跨页的角色Transition 检查一次受控跳转；Journey 根据多个节点事实构建跨阶段检查实例。
